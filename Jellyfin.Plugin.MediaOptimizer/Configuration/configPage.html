In-app interface

Jellyfin has no supported plugin API for its web client, so the dialog has to be injected. The File Transformation plugin does this without touching any files; install it from github.com/IAmParadox27/jellyfin-plugin-file-transformation. Patching index.html works without it but is undone by every Jellyfin update and fails on read-only containers. Either way, the buttons only appear in browser-based clients — never on Android TV, Roku, Kodi or Swiftfin. Everything here works regardless.

Tracks to keep

Comma separated. Every other audio track is removed, which is bit-exact for the ones you keep and is usually the single largest saving available — a foreign-language track on a Blu-ray rip can be a gigabyte on its own. "eng", "en" and "English" all work. Leave empty to keep every track. A file is never left with no audio: if nothing matches, the default track is kept.

Speed

Picks the encoder preset. Going from "smallest file" to "fastest" typically finishes three to five times sooner for a file around 10% larger.
The single biggest speed lever: typically ten to twenty times faster than encoding on the CPU. The trade is size — a GPU needs roughly 50% more bitrate to look as good. Requires hardware acceleration to be set up under Dashboard → Playback → Transcoding.
