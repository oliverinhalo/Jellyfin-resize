In-app interface

Jellyfin has no supported plugin API for its web client, so the dialog has to be injected. The File Transformation plugin does this without touching any files; install it from github.com/IAmParadox27/jellyfin-plugin-file-transformation. Patching index.html works without it but is undone by every Jellyfin update and fails on read-only containers. Either way, the buttons only appear in browser-based clients — never on Android TV, Roku, Kodi or Swiftfin. Everything here works regardless.

Tracks to keep

Comma separated. Every other audio track is removed, which is bit-exact for the ones you keep and is usually the single largest saving available — a foreign-language track on a Blu-ray rip can be a gigabyte on its own. "eng", "en" and "English" all work. Leave empty to keep every track. A file is never left with no audio: if nothing matches, the default track is kept.
Same rules. Leave empty to keep every subtitle track.
Recommended. An untagged track is usually the main one on a single-language release, so removing it would take the audio you actually want.

Speed

Picks the encoder preset. Going from "smallest file" to "fastest" typically finishes three to five times sooner for a file around 10% larger.
The single biggest speed lever: typically ten to twenty times faster than encoding on the CPU. The trade is size — a GPU needs roughly 50% more bitrate to look as good. Requires hardware acceleration to be set up under Dashboard → Playback → Transcoding.

Encoding

Counted in ordinary conversions: a 4K job counts as two, so 2 allows either two ordinary encodes or one 4K one. Keep this at 1 unless the server does nothing else — encoding competes with live transcoding. One job always starts on an idle server, whatever it weighs.
Keeps the server responsive, but slows encoding whenever anything else wants the CPU. Turn it off if the machine is otherwise idle and you want jobs to finish sooner.
Encoding only ever writes to a temporary file, so a job interrupted by a restart or a power cut can safely start again. A job interrupted while moving the finished file into place is always held for review instead.

Safety

Catches corruption that a container probe would miss. Roughly doubles the time a job takes, and is the difference between "probably fine" and "checked".
"Measure it" and "Find the setting" compare the samples against the source frame by frame and report how much worse it looks, as a VMAF or SSIM score. Switch this off to measure size alone, which is a little quicker. It does nothing unless your FFmpeg has the libvmaf or ssim filter; the status panel says which.
